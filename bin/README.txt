Задание №2: Обработка и анализ изображений — Поиск клада

Файл запуска (консольная версия): node lab2_klad.js
Файл запуска (GUI версия):         npm start  (требует qode)

========================================================
ОПИСАНИЕ ПРОЕКТА
========================================================

Программа выполняет анализ изображений с картой клада:
обнаруживает стрелки, строит путь от начальной красной
стрелки до клада и сохраняет результат в новый файл.

СТРУКТУРА ПРОЕКТА

index.js        — GUI интерфейс на NodeGui

simple2.jpg     — тестовое изображение (режим 2)

========================================================
АЛГОРИТМ РАБОТЫ ПРОГРАММЫ
========================================================

1. Загрузка изображения через библиотеку Jimp

2. Предобработка (зависит от режима):
   - Режим 1: без фильтрации
   - Режим 2: размытие (blur, радиус 2) для подавления шума
   - Режим 3: лёгкое размытие (blur, радиус 1)

3. Бинаризация:
   Пиксель считается объектом, если средняя яркость > 50
   (порог подобран вручную под чёрный фон изображений)

4. Выделение связных областей (BFS/заливка):
   Обход в ширину от каждого необработанного пикселя-объекта.
   4-связность (соседи: вверх, вниз, влево, вправо).
   Компоненты с числом пикселей <= 15 отбрасываются как шум.

5. Классификация объектов по среднему цвету компоненты:
   Режимы 1 и 2:
     - Красная стрелка (start):  R > G*1.5 и R > B*1.5
     - Синий клад (end):         B > R*1.2 и B > G*1.1
     - Белые стрелки (arrow):    R>160, G>160, B>160
   Режим 3:
     - Красная стрелка (start):  R > G*1.5 и R > B*1.5
     - Зелёный клад (clover):    G > R*1.3 и G > B*1.1
     - Белые стрелки (arrow):    R>150, G>150, B>150

6. Построение пути:
   Режимы 1 и 2 — жадный алгоритм:
     От красной стрелки жадно выбирается ближайшая белая
     стрелка в радиусе 250 пикселей, пока не кончатся.
     В конце добавляется синий клад (если в радиусе 400 пкс).

   Режим 3 — направленный алгоритм:
     Шаг 1: 2 стрелки строго вниз (dx < 100)
     Шаг 2: 2 стрелки строго вверх (dx < 150)
     Шаг 3: 6 стрелок методом векторного скоринга —
       выбирается компонента с максимальным score:
       score = dot(направление, lastVec)*1200 - dist
       (предпочитаются стрелки в радиусе 280 пкс,
        продолжающие текущее направление движения)
     В конце добавляется зелёный клевер.

7. Отрисовка результата:
   Режимы 1/2: путь рисуется кривой Безье (зелёный цвет).
   Режим 3:    путь рисуется ломаной линией (голубой цвет).
   Клад обводится красной прямоугольной рамкой (отступ 5 пкс).

8. Сохранение: result_<имя_файла> в текущей директории.

========================================================
ИНТЕРФЕЙС — КОНСОЛЬНАЯ ВЕРСИЯ
========================================================

Запуск:
  node lab2_klad.js

Программа задаёт два вопроса:

  Режим (1-simple1, 2-simple2, 3-simple3): _
    1 — для simple1.jpg (чёткое изображение)
    2 — для simple2.jpg (слегка зашумлённое)
    3 — для simple3.jpg (другая схема пути, зелёный клад)

  Имя файла: _
    Введите имя файла, например: simple1.jpg
    Можно указать полный путь: C:\images\simple1.jpg

Результат сохраняется рядом с исходным файлом как:
  result_simple1.jpg  (или result_<введённое_имя>)

========================================================
ИНТЕРФЕЙС — GUI ВЕРСИЯ (NodeGui)
========================================================

Запуск:
  npm start

Элементы интерфейса:

  [Выпадающий список] Выбор режима:
    - Режим 1 (simple1)
    - Режим 2 (simple2)
    - Режим 3 (simple3)

  [Кнопка] "Выбрать карту и запустить"
    Открывает диалог выбора файла (*.png, *.jpg, *.jpeg).
    После выбора автоматически запускает алгоритм.

  [Статус-строка]
    Отображает текущее состояние: обработка / готово / ошибка.

  [Диалоговое окно]
    По завершении сообщает имя сохранённого файла
    или текст ошибки.
